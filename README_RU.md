# Bannerlord Shader Cache Redirector — инструкция на русском

Утилита переносит **локальный shader cache Mount & Blade II: Bannerlord** с системного диска на другой диск без `mklink`/junction.

## Поддерживаемая версия

Только:

```text
Mount & Blade II: Bannerlord v1.3.15.110062
```

Оригинальный `TaleWorlds.Native.dll` должен иметь SHA-256:

```text
9589f5b59c9649461817ac04620e942303590ce93d0b643d17cababd8f581bd3
```

Если хэш другой, патчер ничего не меняет.

## Что меняется

Стандартный путь:

```text
C:\ProgramData\Mount and Blade II Bannerlord\Shaders\
```

По умолчанию в конфиге указано:

```text
D:\MNB\Shaders\
```

Путь меняется непосредственно в native-коде `TaleWorlds.Native.dll`. Оригинальная DLL автоматически сохраняется как:

```text
TaleWorlds.Native.dll.KaiOriginal.bak
```

## Установка

1. Полностью закрой Bannerlord и лаунчер.
2. Скопируй файлы патчера в:

```text
Mount & Blade II Bannerlord\bin\Win64_Shipping_Client\
```

Нужны:

```text
PATCH.bat
RESTORE.bat
KaiShaderPatch.ps1
ShaderRedirector.ini
```

3. Открой `ShaderRedirector.ini` и укажи нужный путь:

```ini
[ShaderCache]
Path=D:\MNB\Shaders
```

4. Запусти `PATCH.bat`.
5. После успешного сообщения запусти игру и проверь, что shader cache появляется в новой папке.

Если Windows не дает изменить DLL в папке игры, запусти `PATCH.bat` от имени администратора.

## Ограничение пути

В этой версии Bannerlord безопасно используется существующий 16-байтовый слот строки. Поэтому путь должен:

- начинаться с буквы локального диска, например `D:\`
- содержать только ASCII-символы
- занимать не больше **15 байт вместе с финальным `\`**

Финальный `\` патчер добавляет сам.

Подходящие примеры:

```text
D:\Shaders
E:\BL\Shaders
D:\MNB\Shaders
```

Слишком длинный путь будет отклонен **до** изменения DLL.

## Смена папки

Можно изменить `Path=` в `ShaderRedirector.ini` и снова запустить `PATCH.bat`. Если патчер узнает свою предыдущую модификацию и рядом сохранена правильная резервная копия, путь будет заменен.

## Откат

Запусти:

```text
RESTORE.bat
```

Оригинальная DLL будет восстановлена только после проверки хэша резервной копии.

## Важно

- Не применяй патч к другой версии Bannerlord.
- После обновления игры или проверки файлов Steam патч может исчезнуть.
- Изменение native DLL делает исходную цифровую подпись файла недействительной.
- Перед мультиплеером, обновлением игры или диагностикой лучше восстановить оригинальную DLL.
- Старый shader cache автоматически не удаляется.
- Сам `TaleWorlds.Native.dll` в репозитории не распространяется.
