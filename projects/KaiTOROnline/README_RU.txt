KaiTOR Co-op v1.3.15.13
ТЕСТОВАЯ СБОРКА — Bannerlord 1.3.15.110062 + The Old Realms 1.3.15
Языки: Русский / English
Максимум одновременно: 4 игрока
UDP-порт кооператива: 4200

УСТАНОВКА
1. Полностью закрой Bannerlord и лаунчер TaleWorlds.
2. Скопируй папку Modules\Coop из архива в <Bannerlord>\Modules\Coop.
   При запросе замени предыдущую папку Coop.
3. The Old Realms 1.3.15 должен быть установлен отдельно. KaiTOR не распространяет файлы TOR или Bannerlord.
4. Для первого live-теста дополнительные игровые моды можно оставить выключенными.
5. Поддерживаемые дополнительные Steam-модули: KaiCleave — v1.3.15.31, KaiTOR Stability — v1.3.15.50, KaiTOR Portrait Fix — v1.3.15.60. На сервере и у всех клиентов должен быть одинаковый активный набор и точные версии. Workshop-копии launcher подключает временно.

ЗАПУСК АВТОРИТАТИВНОГО СЕРВЕРА КАМПАНИИ
1. Запусти START_KAITOR_COOP.bat из корня архива.
2. Укажи корневую папку Bannerlord.
3. Введи точное имя сохранения кампании.
4. Укажи имя сервера. По умолчанию: KaiTOR Co-op | TOR RU Test.
5. Выбери видимость сервера и при необходимости пароль. Для появления в общем списке Steam используй «Публичный» (в панели это режим по умолчанию).
6. Нажми «Проверить». Сервер не запускаем, пока Preflight не покажет PASS.
7. Нажми «Запустить сервер».
8. После запуска Bannerlord.exe /singleplayer /server панель должна показать «ЗАПУЩЕН».

ПОДКЛЮЧЕНИЕ КЛИЕНТА
1. Запусти Bannerlord 1.3.15.110062 с TOR 1.3.15 и KaiTOR Co-op.
2. Базовый порядок: TOR_Armory -> TOR_Environment -> TOR_Core -> [KaiCleave] -> [KaiTOR_Stability] -> [KaiTOR_PortraitFix] -> Coop. Если активны Cleave или Portrait Fix, Bannerlord.Harmony загружается первым.
3. В главном меню выбери «Подключиться к KaiTOR».
4. По умолчанию откроется «Лобби Steam». Нажми «Обновить», найди сервер по имени и подключись из списка.
5. В строке сервера отображаются имя, игроки x/4, версия KaiTOR и статус совместимости. Несовместимая сборка блокируется.
6. «Прямое подключение» по IP остаётся резервным вариантом; порт по умолчанию — 4200.

STEAM / VPN
- Перед Public/Friends запуском Preflight проверяет, что Steam запущен и локальные UDP 27315/27316 свободны. Эти порты НЕ нужно пробрасывать на роутере для Steam P2P/Relay; они должны быть только свободны на ПК хоста.
- «Сервер: ЗАПУЩЕН» означает, что процесс Bannerlord работает. Отдельный статус «Steam: ЛОББИ ГОТОВО» означает, что Steam game-server вошёл в сеть, lobby создан и P2P tunnel слушает подключения.
- Совместимость привязана к точной CI-сборке: BuildVersion содержит commit SHA. Одинакового номера модуля недостаточно, если DLL собраны из другого коммита.
- Для обычного подключения через «Лобби Steam» KaiTOR использует Steam P2P/relay tunnel. Публичный IP вводить не требуется.
- Это основной режим для хоста, который работает через VPN или находится за NAT/CGNAT, при условии что сам Steam и Steam Networking работают через этот VPN.
- Проброс UDP 4200-4201 нужен только для прямого IP-подключения/резервного маршрута. Steam tunnel не зависит от ручного ввода IP.

ПЕРВЫЙ LIVE-ТЕСТ
A. Подключи игрока 1 и проверь загрузку кампании.
B. Подключи игрока 2: у обоих должны быть отдельные герои/отряды и независимое движение.
C. Подключи игроков 3 и 4.
D. Проверь, что пятый уникальный игрок получает отказ.
E. На авторитативном сервере выполни: coop.debug.kaitor.snapshot4p
F. Проверь четыре уникальных Controller/Hero/Clan/MobileParty.
G. Не перезапуская сервер, пройди одно столкновение и один бой.
H. Сохрани кампанию, останови сервер, запусти снова и подключись в другом порядке: D -> B -> A -> C.
I. У каждого игрока должны восстановиться исходные Hero/Clan/MobileParty.

ТЕСТ СРАЗУ СЧИТАЕТСЯ ПРОВАЛЕННЫМ ПРИ
TypeLoadException, MissingMethodException, MissingFieldException, FileLoadException,
BadImageFormatException, ReflectionTypeLoadException, Harmony patch failure,
дублировании героя/отряда, связанном движении двух игроков или рассинхроне состояния мира.

ЛОГИ
Кнопка «Открыть лог» находится в серверной панели. При ошибке сохраняй полный серверный лог и относящиеся к моменту ошибки клиентские логи.

ВАЖНО
ServerConsole — вспомогательный сервис rendezvous/listing/NAT. Это НЕ сервер мира кампании.
Авторитативный мир работает в отдельном процессе Bannerlord, запущенном с /singleplayer /server.
Нативный no-render/headless режим TOR этой сборкой не заявляется.
